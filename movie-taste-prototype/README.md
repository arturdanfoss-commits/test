# Movie Taste Lab

Прототип сайта, который за 20 быстрых сравнений фильмов понимает вкус пользователя и предлагает 5 новых фильмов из отдельного списка рекомендаций.

Public Vercel URL: https://movie-taste-prototype.vercel.app

## Что работает

- выбор между левым и правым фильмом;
- два этапа опроса: разведка вкуса и уточнение;
- русские названия фильмов с оригинальными названиями;
- постеры из TMDB image CDN;
- финальная подборка из 5 фильмов, которые не показывались в опросе.

## Запуск

```bash
npm install
npm run dev
```
