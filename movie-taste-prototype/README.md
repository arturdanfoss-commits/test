# Movie Taste Prototype

Прототип сервиса для подбора фильмов по вкусу пользователя.

Пользователь проходит короткий опрос: на каждом шаге выбирает один из двух фильмов. После 20 выборов сервис показывает 5 рекомендаций из отдельного пула фильмов, которые не использовались в опросе.

Публичная версия: https://movie-taste-prototype.vercel.app/

## Что внутри

- Next.js приложение
- русскоязычный интерфейс
- постеры фильмов в опросе
- 20 раундов выбора
- случайные рекомендации из отдельного списка
- защита от повторения недавно показанных рекомендаций

## Запуск локально

```bash
npm install
npm run dev
```

После запуска сайт откроется на `http://localhost:3000`.
